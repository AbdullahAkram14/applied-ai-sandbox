# M6 — Other Tools Tour

## Copilot — installed

Observation: Copilot provides quick inline code suggestions while typing and is useful for boilerplate code, but it has less awareness of project-specific context than Claude Code.

## Cursor — demo'd

Observation: Cursor combines an editor and AI agent in one interface, making it convenient for multi-file changes, while Claude Code feels stronger for terminal-based workflows and repository-wide tasks.

## Gemini CLI (or Codex CLI) — installed/demo'd
- Same prompt comparison: Gemini CLI installed and authenticated, but the auth flow kept reopening, so I used the demo/fallback path. It feels similar to Claude Code as a terminal agent, but Claude Code was smoother and more reliable for this repo.

## Chat (Claude.ai or ChatGPT) — used for
- Observation: ChatGPT was useful for planning, explaining tool differences, and helping me decide what to write in my notes, but it does not directly edit or run files like Claude Code.
## Tool decision matrix

| Situation | Tool I'd reach for | Why |
| --- | --- | --- |
| Multi-file feature with good CLAUDE.md | Claude Code | It can read project files, follow repo context, and run commands. |
| 5-line helper autocomplete while typing | GitHub Copilot | It gives fast inline suggestions without needing a full prompt. |
| Brainstorm three design approaches | ChatGPT/Claude.ai | Chat is best for planning before touching code. |
| Review a teammate's PR for security issues | ChatGPT/Claude.ai | It can focus on risks and review logic without modifying files. |
| Cross-file refactor with consistent renames | Cursor | The AI-native editor makes multi-file diffs easier to review visually. |
| Learning a new library's API | ChatGPT/Claude.ai | It explains concepts and lets me ask follow-up questions. |
